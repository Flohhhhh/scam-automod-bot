# Scripts

- `npm run dev`: start Nest in watch mode.
- `npm run build`: compile production output to `dist/`.
- `npm start`: run compiled production output.
- `npm test`: run Jest unit tests.
- `npm run format` / `format:check`: write or verify Prettier formatting.
- `npm run lint`: run ESLint with warnings treated as failures.
- `npm run typecheck`: run TypeScript without emitting files.
- `npm run validate:handlers`: verify handler files are registered and decorated.
- `npm run create:command -- <name> [description]`: scaffold and register a slash command.
- `npm run create:listener -- <name> <event>`: scaffold and register a Discord event listener.
- `npm run check`: run every required quality gate.
